# Pathleap 1.0.9 发布说明

发布日期：2026-11-13
版本：`1.0.9`（上一正式版 `1.0.8`）
tag：`v1.0.9`

版本号按 [版本号规则](版本号规则.md) 从 `1.0.8` 升 patch 得到 `1.0.9`（未超过 10，不进位）。

本版全部围绕**快速切换栏（QS）**：接入真实搜索、按主搜索窗重做搜索框、把栏压回与对话框同层、
去掉栏内常驻说明文字并改为首次引导 + 设置帮助页。主搜索窗、索引、更新与安装逻辑不变。

## 1. QS 栏接入真实搜索

- 栏头是一个可输入的搜索框：不输入时列最近文件夹（最多 6 个，3 列），输入即查索引，显示结果列表；
- `↑` / `↓` 移动选中，`Enter` 打开（有文件对话框时注入路径并跳转），`Esc` 清空或退出输入态；
- 输入防抖 160ms，查询走既有命名管道，不新增服务端接口；
- 空结果有明确空态文案，不显示空白栏。

实拍：

| # | 场景 | 结果 |
| --- | --- | --- |
| 48 | 无输入（改版前基准） | 960×206，6 格 3 列 |
| 49 | 真实键入 `path` | 960×484，6 条结果，占位符消失、光标在尾部 |
| — | 点击不闪烁 | 900ms 内 378,475 个采样，`visChanges=0 barMoves=0 dlgMoves=0` |

## 2. 栏与对话框同层

栏是对话框的 owned 窗口：`GWLP_HWNDPARENT` 指向对话框、样式 `WS_EX_TOOLWINDOW | WS_EX_NOACTIVATE`，
**没有 `WS_EX_TOPMOST`**。z 序实测（`GetWindow(GW_HWNDPREV/NEXT)` + `IsWindowVisible` + 像素采样）：

| 场景 | 实测 |
| --- | --- |
| 空闲吸附 | `dialogAboveBarOffset=1`，栏与对话框矩形无重叠 |
| 其它应用盖住对话框 | 对话框像素被遮挡；栏 `IsWindowVisible=False`，随宿主一起被盖 |
| 对话框回前台 | 栏恢复可见 |
| 最小化 / 还原 | 栏 `True → False → True` |
| 多对话框 | 各自 owner，切前台只显示对应那条；关掉一个不影响另一个 |
| 宿主重新激活 | **部分未达标**：系统会把 owned 栏抬到宿主之上，已补 `ReorderBelowOwner()` + 150/700ms 延后重排，实测仍为栏在对话框上方一级 |

未达标项的影响与限制见 [quick-switch-attach.md](quick-switch-attach.md)「栏与对话框同层」小节；
不写成「已修复」。

## 3. 搜索框按主搜索窗重做

设计稿的快速切换区域只有标题/副标题/计数，没有搜索框，且用户要求删掉这行文字，因此改为对齐主搜索窗：

| 对齐项 | 主搜索窗 | QS 栏 |
| --- | --- | --- |
| 字号/字重 | 20 DIP SemiBold | 14 DIP SemiBold |
| 高度 | `MinHeight=30` | `Height=26` |
| 内边距 | 18,18,18,16 | 12,9,12,9 |
| 品牌点 | 22×22 / 圆角 7 | 18×18 / 圆角 5 |
| 占位符 | 「搜索文件、文件夹或程序…」/ `Text4Brush` | 「搜索文件与文件夹」/ `Text4Brush` |
| 焦点态 | 无描边、透明底 | 同主窗 |
| 选中高亮 | `#4D3D6EF7` | `#4D3D6EF7` |

对比图 `docs/shots/55-quickbar-searchbox-compare.png`（同位置裁切放大 2 倍，上=改版前，下=改版后）；
三态 `58-quickbar-noguide.png`（无输入）、`49-quickbar-search.png`（输入中）、`54-quickbar-focus.png`（聚焦）。
**未覆盖**：鼠标悬停态没有像素证据。

## 4. 去掉常驻说明文字、首次引导、设置帮助页

| 项 | 改版前 | 1.0.9 |
| --- | --- | --- |
| 栏头 | 标题「快速切换」+ 副标题「已打开的文件夹」+ 计数 | 品牌点 + 搜索框 + 计数 |
| 栏高 | 103 DIP | **82 DIP**（省 21 DIP） |
| 首次引导 | 无 | 三步（不输入=最近文件夹 / 输入即搜索 / Enter 打开）+ 跳过，只出现一次 |
| 帮助 | 无 | 设置新增离线「帮助」页：主窗搜索、QS 与键盘、全局热键、索引与权限、更新检查 |

对比图 `docs/shots/60-quickbar-cleanup-compare.png`；引导 `56-quickbar-guide.png`、跳过 `57-quickbar-skip.png`、
二次唤出 `58-quickbar-noguide.png`、帮助页 `59-settings-help.png`。

## 5. 回归与验收口径

- 本轮全部实拍走离屏 `PrintWindow(hwnd, hdc, 2)`（`%TEMP%\pathleap-scaling\PrintWindowLp.exe`），不依赖窗口是否在最前；
- 需要真实前台的项（键入、拖动、遮挡、点击）攒成一批，一次会话内跑完，结束后恢复原前台；
- 采样原文 `%TEMP%\pathleap-scaling\qs-probe-final4.txt`，脚本 `tools/Test-LpQuickBarProbe.ps1`；
- 拖动跟随：12 步 × 6px，栏位置延迟 11.54–19.07ms，每步 `settled=True`；
- 栏右边缘逐像素：`0:#383A40 1:#383A40 2:#171A21`，只剩一层 DWM 边框。

## 6. 已知限制

1. 输入态时栏必须成为前台才能收键盘，此时 z 序在对话框之上；栏在对话框外侧，不遮挡内容；
2. 宿主重新激活后栏可能被系统抬到宿主之上（见 §2），未完全消除；
3. QS 搜索框悬停态无像素证据；
4. 混合 DPI 多屏、真实网络更新等既有未验证项同 1.0.8。
