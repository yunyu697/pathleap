# Pathleap 1.1.0 发布说明

发布日期：2026-11-14
版本：`1.1.0`（上一正式版 `1.0.10`）
tag：`v1.1.0`

版本号按 [版本号规则](版本号规则.md) 进位：`patch` 上限是 10，`1.0.10` 再升 patch 进位为 `1.1.0`
（不存在 `1.0.11`，`Build-Lp.ps1` 与 CI 都会拒绝越界版本）。

本版是 1.0.10 的返工，起因是实测否掉了 1.0.10 的三处取舍：栏被改成直角、栏与对话框之间 0 间隙、
改尺寸时栏跟不上。三处一起改，不再用「牺牲一项换另一项」：圆角、间距、跟手同时成立，
并顺带把全站窗口圆角统一到 8 DIP。

## 1. 圆角：QS 栏恢复圆角，全站统一 8 DIP

1.0.10 的做法是 `DWMWCP_DONOTROUND` + 客户区填满，四角不再露白，但栏成了直角，与设计稿和主窗都不一致。

现在改成：DWM 圆角裁剪（`DWMWCP_ROUND`）+ 客户区整块填不透明面面色 + **关掉 DWM 描边**
（`DWMWA_BORDER_COLOR = DWMWA_COLOR_NONE`）。1.0.9/1.0.10 的「角上白边」其实是两处叠加：
窗口没有逐像素透明、客户区没画满露出窗口白底；外加 DWM 描边按窗口矩形画方角。
两处都去掉后圆角是真实的弧，四角没有任何白块。

全站同口径（详见 [1.1.0-圆角统一清单.xlsx](1.1.0-圆角统一清单.xlsx)）：主搜索窗 14 → 8、QS 栏 10（1.0.10 为直角）→ 8、
设置窗 8 → 8（改由 DWM 出弧）、更新窗 12 → 8、关于窗 12 → 8、托盘菜单 9 → 8；
组件级小圆角（图标底 40×40/44×44、徽标 pill、开关轨道、版本胶囊）保持原值，它们不是窗口圆角。

**关于主搜索窗的如实说明**：它此前并没有白块问题——XAML 的 14 DIP 自绘圆角一直被 DWM 的 8 DIP 裁剪盖住，
视觉半径本来就是 8 DIP，改前改后四角读数完全一致（见下表）。本次只做源码归一（XAML 圆角归 0，窗口里只留一套圆角），
主窗唯一可见的变化是首次引导卡（内嵌卡片、不受 DWM 裁剪）从 14 DIP 变成 8 DIP；
底部搜索条的两个下角原本就被 DWM 裁成 8，改后源码与实际一致。

另外核实了 DWM 描边：窗口为 `ROUND` 时描边跟随弧形（不是方角），主窗因此保留系统描边；
1.0.9/1.0.10 的栏是 `DONOTROUND`，描边才按矩形画。QS 栏继续保持 `drawBorder:false`，四角更干净。

## 2. 间距：栏与对话框之间 8 DIP

`QuickSwitchLayout.GapDip = 0 → 8`。依据是设计稿的间距体系：栏内 `gap:8`、内边距 18/20、行间距 6/8，
8 是其中最小的一档组间距；栏与对话框是「同组不同层」的两个面板，取这一档既连成整体又留出层次。
8 DIP 也大于对话框窗口矩形比可视外框多出的不可见缩放边框（200% 实测 11px = 5.5 DIP），
所以代码间距、视觉间距、热区让位三件事同时成立。

| 项 | 1.0.10 | 1.1.0 |
| --- | --- | --- |
| 拖动前 | 可视下边 1058 / 栏上边 1058 → 0px | 1058 / 1074 → **16px = 8 DIP** |
| 拖动后 | 1118 / 1118 → 0px | 1118 / 1134 → **16px = 8 DIP** |
| 水平居中偏差 | 0px | 0px |
| 翻到上方 | 0px | 8 DIP（`gapPx` 同为 16px，200%） |

裁切图：[间隙 3×](shots/63-r1-gap-seam-3x.png)、[右端圆角+间隙 6×](shots/64-r1-gap-right-corner-6x.png)、

## 3. 缩放跟手：底边热区让出，跟随改为几何事件驱动

- 位置尺寸只由 `EVENT_OBJECT_LOCATIONCHANGE` → `PositionAttached()` 驱动，与对话框同一帧完成；
- `OnFollowTick()` 不再调用 `PositionAttached()`，只做可见性与 z 序自愈（`EnsureAboveDialog()`），
  **31ms 轮询不参与跟随定位**；
- `PositionAttached()` 在几何未变时直接返回，不重排内容。

底边中点竖向探测（x = 对话框窗口矩形中线，200%）：

| 位置 | 1.0.10（tag 重编实测） | 1.1.0 |
| --- | --- | --- |
| 栏窗口矩形 vs 对话框窗口矩形 | 重叠 11px | 让出 5px（-5px） |
| 下边 -1…-10px `WindowFromPoint` | 全部命中栏的 DesktopChildSiteBridge | 全部命中 `#32770` 对话框 |
| 同上 `WM_NCHITTEST` | 0xF（鼠标到不了对话框） | **0xF = HTBOTTOM** |
| 左右 1/4 处对照 | 命中对话框 | 命中对话框 |

连续改尺寸 120 帧 × 16ms（每帧 1ms 级采样）：

| 指标 | 1.0.10 | 1.1.0 |
| --- | --- | --- |
| 采样数 | 410,230 | 302,095 |
| 可见性跳变 | 0 | 0 |
| avgDev | 0.03 | 0.25 |
| maxDev | 4.0 | 4.0（除第 0 帧瞬时 60） |
| 偏差分布 | 未统计 | p50=0 p90=1 p95=2 p99=3，>4px 共 124 个采样 |
| 拖动结束 | settleMs=0.0 dev=0.0 | **settleMs=0.0 dev=0.0 visible=True** |

第 0 帧的 60px 出现在一次性 +60px 跳变、事件尚未派发的瞬间（124/302,095 采样），第 1 帧起每帧 max ≤4px、
每秒都回 0，不是持续追赶；p95=2px 的残余是 DIP→px 取整（200% 下对话框底边常落在奇数像素），不随时间累积。

## 4. z 序未回退

与 1.0.10 同口径，8 个场景全部 `bar-above between=0`：空闲吸附、第三方窗口插到正上方、点击进输入态、
点回对话框退出、最小化/还原、点标题栏重新激活、连续改尺寸后、多对话框切换。
两条长序列 `badSamples=0`（703,569 与 873,228 采样），`final=bar-above:0 vis=True`，`topmost=False`、`ex=0x8000180`。

## 5. 影响范围

- 只改窗口外侧轮廓与 QS 栏间距：所有窗口的客户区尺寸、布局、内容位置均未变；
- 主窗 XAML 圆角 14 → 0、改由 DWM 出 8 DIP 弧，阴影与抗锯齿由 DWM 提供，窗口阴影范围不变；
- QS 栏与对话框间距 0 → 16px（200%），栏相对对话框的位置整体下移 16px，栏自身尺寸不变；
- z 序、输入态、多对话框、翻上方等既有行为与 1.0.10 一致（见 §4 与 `docs/quick-switch-attach.md`）；
- 组件级圆角（图标底、徽标、开关轨道、胶囊）未改，清单见 xlsx 第 9–13 行。

## 6. 发布

产物与 1.0.10 同规则：便携 zip + Windows 安装包，版本号来自 `Directory.Build.props` 的 `PathleapVersion=1.1.0`。
