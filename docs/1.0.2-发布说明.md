## 1. 本次变更

1. **安装范围二选一**：安装包向导第一步可选「仅为我安装」（默认）或「为所有用户安装」；
   也支持静默参数 `/CURRENTUSER`、`/ALLUSERS`。安装范围写入 `HKCU/HKLM\Software\Pathleap` 的
   `InstallScope`、`InstallDir`、`InstallVersion`（64 位视图），卸载时删除对应值，不写 WOW6432Node。
2. **设置新增「安装与权限」卡片**：显示当前安装模式（仅当前用户 / 所有用户 / 便携版）、维护者、
   安装目录，并说明切换安装范围需要重新运行安装包。
3. **「始终以管理员身份运行」开关**：计划任务 `Pathleap-Elevated-<用户SID>`，`RunLevel=HighestAvailable`、
   无触发器；启动器写交接文件后用 `schtasks /Run` 拉起，目标进程以 `--elevated-launch` 恢复原参数。
   **不使用 Run 注册表项**。注册/取消任务各需要一次 UAC。
4. **UIPI 限制在界面中明确提示**：提权窗口完整性级别更高，资源管理器无法把文件/文件夹拖进来；
   卡片内直接写出，不隐藏这一代价。

## 3. 「始终以管理员身份运行」实测

日志：`%LOCALAPPDATA%\Pathleap\logs\ui-20261107.log`。

| 步骤 | 结果 |
| --- | --- |
| 打开 `alwaysRunAsAdmin` 后启动 `--tray` | 启动器退出码 0；计划任务拉起新进程，`elevated=True` |
| `--status` 经命名管道转发 | `ok=True`，PID 与提权进程一致 |
| `--quit` 经命名管道转发 | `ok=True`，2 秒后进程数 0 |
| 删除计划任务后再 `--tray` | `elevated=False`，`--quit` 仍正常 |
| 注册表 Run 项 | 未写入（实现只用计划任务） |

**未验证**：在设置界面用鼠标点击 `LpSwitch` 完成「注册任务 → 重启提权」的完整链路。该控件没有可自动化的
UIA Invoke 模式，本次未做 UI 自动化点击；已测的是「配置为 true 时启动器按计划任务提权」这一段。
**未验证**：提权后资源管理器拖放的实拍（受 UIPI 限制，预期不可拖入）。
