# Pathleap 1.0.8 发布说明

发布日期：2026-11-13
版本：`1.0.8`（上一正式版 `1.0.7`）
tag：`v1.0.8`

版本号按 [版本号规则](版本号规则.md) 从 `1.0.7` 升 patch 得到 `1.0.8`（未超过 10，不进位）。

本版只改**主搜索窗的尺寸与位置**：宽度从固定 660 DIP 改为光标所在显示器工作区宽度的一半，
唤醒时顶边固定在工作区高度的 1/4 处（原来按 1/5 定位、垂直方向接近居中）。高度保持 436 DIP 不变。
索引、搜索、更新与其它界面不变。

## 1. 主搜索窗：半屏宽 + 顶边 1/4

### 1.1 规则

| 项 | 1.0.7 及更早 | 1.0.8 |
| --- | --- | --- |
| 宽度 | 固定 660 DIP | 光标所在显示器**工作区宽度的 1/2**（DIP 计算后换算物理像素） |
| 水平位置 | 工作区居中 | 工作区居中（不变） |
| 顶边 | 工作区高度 × 0.2 | 工作区高度 × **0.25**（不随窗口高度居中） |
| 高度 | 436 DIP | 436 DIP（不变） |
| 窄屏下限 | 无（660 固定） | 半宽低于 **560 DIP** 时取 560 DIP，且不超过工作区宽度 |

目标屏幕与设置窗一致：取**光标所在显示器**，`MonitorFromCursor` 失败时退回主屏，复用同一套降级路径。
宽度先按 DIP 求一半再一次性换算物理像素，避免逐次取整导致高 DPI 下宽度抖动；`X` 按
`工作区左 + (工作区宽 − 窗宽) / 2` 整数计算，同一缩放档下每次唤醒位置一致。

实现：`src/Pathleap.UI/Platform/MainWindowLayout.cs`（新增），`MainWindow.PositionWindow`
改为调用它；`AppConfig.WindowWidth` 已失效并移除，`WindowHeight` 保留。

### 1.2 实拍核对

`--layout-probe`（`GetDpiForMonitor` 真实读数）闸门确认缩放后，用 `BitBlt(CAPTUREBLT)` +
`DWMWA_EXTENDED_FRAME_BOUNDS` 抓物理像素，再按工作区边界算比例：

| 缩放 | 窗宽 / 工作区宽 | (窗顶 Y − 工作区顶) / 工作区高 | 水平居中偏差 | 窗高 |
| --- | --- | --- | --- | --- |
| 200% | 1440 / 2880 = **0.5** | (426 − 0) / 1704 = **0.25** | 0 px | 872 px（436 DIP） |
| 100% | 1440 / 2880 = **0.5** | (438 − 0) / 1752 = **0.25** | 0 px | 436 px（436 DIP） |

- 200%：工作区 2880×1704（底部任务栏 96 px），窗 `L=720 T=426 1440×872`；
- 100%：工作区 2880×1752（底部任务栏 48 px），窗 `L=720 T=438 1440×436`；
- 截图：`44-main-scale200-recent` / `45-main-scale200-results` / `46-main-scale100-recent` /
  `47-main-scale100-results`（均在 `docs/shots/`）；
- 125% / 150% **未实拍**：本机两块屏当前均为 200%，只切了 100% 一档做对照；
  两档与合成三屏（左 150% / 主 125% / 右 100%）、1024 DIP 窄屏下限由探针 `mainWindow` 节点数值留档。

### 1.3 加宽后的行布局复查

- 行结构为「30 DIP 图标 + 星号内容列 + 右侧自动列」，加宽只让内容列变宽，不改变行高与间距；
- 名称走 `LpHighlightText`，长名按字符省略；路径 `TextTrimming=CharacterEllipsis` 保留；
- 时间与类型标签贴右（资源管理器惯例），行中部留空属预期；两档实拍均无溢出、无文字贴边；
- 空态文案与底栏提示仍居中/贴边距排列，无拉伸变形；
- 失焦即隐藏、`Esc` 清空并隐藏、`Enter` 打开选中项等既有行为未改动。

## 2. 已知限制

- 混合 DPI 多屏（两屏缩放不同）下主窗几何只有探针数值，未做真机实拍；
- 125% / 150% 本版未实拍，结论以探针数值留档为准；
- 窄屏下限 560 DIP 只在探针的 1024×768 合成工作区上验证，未使用真实小屏。
