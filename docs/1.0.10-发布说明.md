# Pathleap 1.0.10 发布说明

发布日期：2026-11-13
版本：`1.0.10`（上一正式版 `1.0.9`）
tag：`v1.0.10`

版本号按 [版本号规则](版本号规则.md) 从 `1.0.9` 升 patch 得到 `1.0.10`。

本版只改**快速切换栏（QS）**的层级与几何，全部来自实测反馈：

1. 别的窗口会插在栏与对话框之间；
2. 栏应贴着对话框下边缘，此前留有 2–4px 缝（200% 下实测 15px 可视缝）；
3. 调整对话框尺寸时栏闪烁，四角出现白边。

主搜索窗、索引、更新与安装逻辑不变。

## 1. z 序：栏固定在对话框正上方一层

改动：

- 插入位置从「对话框之后（下面）」改为「宿主正上方那个窗口的下面」：
  `GetWindow(宿主, GW_HWNDPREV)` 作为 `SetWindowPos` 的 `hWndInsertAfter`，栏与宿主之间不可能再夹窗口；
- 几何移动与 z 序重排分开设置：几何用 `SetWindowPos(..., SWP_NOZORDER)`，z 序单独一次 `SetWindowPos`，
  避免参照窗口刚好被销毁时整次调用失败（那会让栏卡住不动）；
- 去掉 1.0.9 的 150/700ms 两次延后重排；
- 首次挂载后立即插到宿主正上方，空闲态不再依赖后续前台事件。

**没有用 `WS_EX_TOPMOST`**：探针每轮打印 `topmost=False`、`ex=0x8000180`（TOOLWINDOW+NOACTIVATE）。

实测（200% 单屏，`GetWindow(GW_HWNDPREV/NEXT)` 逐条枚举，`between` 只计可见窗口）：

| 场景 | 1.0.9 | 1.0.10 |
| --- | --- | --- |
| 空闲吸附 | `bar-below between=0`（栏反而在对话框下方） | `bar-above between=0` |
| 点击进入输入态 | `bar-above between=5`（夹了 5 个可见窗口） | `bar-above between=0` |
| 退出输入态 1.2s 序列 | `badSamples=100%`（755,249/755,249） | `badSamples=0`（743,610 采样） |
| 点标题栏重新激活 1.5s 序列 | 采样无效（栏已被隐藏） | `badSamples=0`（931,737 采样） |
| 其它程序遮挡后回前台 / 最小化还原 / 多对话框切换 | 遮挡与还原可见性正确，多对话框时后台栏未隐藏 | 全部 `between=0`，后台栏 `visible=False` |

## 2. 栏贴着对话框下边缘（间隙 0）

改动：贴边基准从 `GetWindowRect` 的下边改为 DWM 可视外框（`DWMWA_EXTENDED_FRAME_BOUNDS`）的下边，
`GapDip = 0`；下方空间不足翻到上方时贴在可视上边，同样 0 间隙。

| 项 | 1.0.9 | 1.0.10 |
| --- | --- | --- |
| 拖动前可视间隙 | 15px | **0px** |
| 拖动后可视间隙 | 15px | **0px** |
| 水平居中偏差 | 0px | 0px |
| 翻到上方（对话框底边压到工作区底边） | — | 上贴间隙 **0px**（8,479 采样，`visChanges=0`） |
| 100/125/150/200% 离屏几何 | 2 / 2 / 3 / 4px | 全部 **0px**（`gapMatches=true`） |

取舍：0 间隙后栏会盖住对话框窗口矩形底部约 4px（200%）的不可见缩放热区，底边中段改为拖动栏，
左右下角仍是对话框的热区。

## 3. 缩放闪烁与角上白边

改动：

- 客户区整块填满（`RootGrid` 与 `RootBorder` 同色）；
- `RootBorder` 圆角归 0，DWM 圆角偏好改为 `DWMWCP_DONOTROUND`；
- 跟随改为常驻轮询（设定 16ms，实测约 31ms 一拍），几何未变时只读不写、不重排 z 序；
  事件整段丢失（最小化还原后实测一条都不再送达）时由它自愈；
- 前台归属每拍从 `GetForegroundWindow()` 实时判定（`GW_OWNER` 逐级上行，不用 root owner，避免多对话框时两条栏同时可见）。

连续改尺寸（60Hz × 120 帧，1ms 级采样）：

| 指标 | 1.0.9 | 1.0.10 |
| --- | --- | --- |
| 每帧偏差 `avgDev` | 15.00px | **0.03px** |
| 最大偏差 `maxDev` | 45.0px | 4.0px |
| 偏差 >2px 采样占比 | 100% | 0.41% |
| 拖后 600ms 收敛 | `dev=15.0`、`visible=False` | `dev=0.0`、`visible=True` |
| 点击 900ms 可见性翻转 | 4 次（隐藏→显示→隐藏→显示） | 0 次 |

四角像素（200%，角点 / 内缩 1 / 2 / 5px）：

| 角 | 1.0.9 | 1.0.10 |
| --- | --- | --- |
| 左上 | `#B8B8B8 / #B8B8B8 / #B9B9B9 / #BBBBBB` | 全 `#171A21` |
| 右上 | `#111111 / #A3A3A3 / #B4B4B4 / #B6B6B6` | 全 `#171A21` |
| 左下 | `#F5F5F5 / #F5F5F5 / #F5F5F5 / #F5F5F5` | 全 `#171A21` |
| 右下 | `#FFFFFF / #FFFFFF / #FFFFFF / #FFFFFF` | 全 `#171A21` |

来源：客户区没画满 + 10 DIP 圆角 + 自绘描边三层叠加（右下纯白是自绘描边/底色透出的窗口背景，右上 `#111111` 是 DWM 边框色），
不是对话框阴影。对比图：`docs/shots/61-*-corner-*-8x.png`、`62-*-seam-2x.png`。

## 5. 已知限制

1. 栏改直角，与主窗的圆角风格不一致（0 间隙下圆角必然在四角露出后面的像素）；
2. 对话框底边中段的不可见缩放热区被栏覆盖；
3. 对话框最大化时上下都没有空间，栏仍回退到工作区顶部附近，不贴边（1.0.9 既有行为，本轮未改）；
4. 输入态时栏必须成为前台才能收键盘，此时它在 z 序上高于对话框，但仍紧贴对话框正上方（`between=0`）；
5. 混合 DPI 多屏 `WM_DPICHANGED` 重排、真实网络更新等既有未验证项同 1.0.8。
