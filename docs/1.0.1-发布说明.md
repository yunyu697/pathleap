# Pathleap 1.0.1 发布说明

发布日期：2026-11-07
版本：`1.0.1`（上一正式版 `1.0.0`）
tag：`v1.0.1`
产物：

| 产物 | 大小（本地实测） | 说明 |
| --- | --- | --- |
| `Pathleap-1.0.1-win-x64.zip` | 11,289,996 字节（10.77 MB） | 便携版 |
| `Pathleap-1.0.1-win-x64-setup.exe` | 8,337,280 字节（7.95 MB） | 安装包（Inno Setup 6） |

## 1. 本次变更

1. **新增 Windows 安装包**：可选择安装目录、创建开始菜单快捷方式、桌面快捷方式可选、写入当前用户卸载项、
   安装完成可选择启动 UI；UI 启动后自动拉起同目录服务。
2. **修复打包缺失原生依赖**：此前 zip 只复制 UI 输出目录的顶层文件，漏掉
   `runtimes\win-x64\native` 下的 Windows App Runtime 原生引导 DLL，导致干净机器上解压后无法启动。
   现在按相对路径递归复制（仅保留 `win-x64` 运行时），zip 与安装包都包含该目录。
3. **README 重写**：按当前真实状态描述能力、索引/搜索方式、实测数据、安装前提、目录结构、构建与版本规则、
   已知限制，并加入「每个里程碑/发版同步更新 README」的约定与发布检查清单。
4. **清除禁用词**：当前源码、文档、界面文案、资源、CI 配置与产物中均不再包含该词。

## 2. 安装包行为与卸载取舍

- 安装范围：当前用户（默认 `%LOCALAPPDATA%\Programs\Pathleap`），不需要 UAC；`DefaultDirName={autopf}\Pathleap`，
  用户可在向导中修改目录。
- 快捷方式：开始菜单 `Pathleap` 与「卸载 Pathleap」；桌面快捷方式为可选任务，默认不勾选。
- 卸载项：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\{AppID}_is1`，显示名称 `Pathleap <版本>`。
- 卸载清理：程序文件、快捷方式、卸载注册项全部移除；安装/卸载前会结束正在运行的 `Pathleap.UI.exe` 与
  `Pathleap.Service.exe`，避免文件占用。
- **配置、日志、索引缓存默认保留**（`%LOCALAPPDATA%\Pathleap`）：这样升级/重装不需要重建索引，也不会丢日志。
  交互式卸载会额外询问是否删除该目录；选「是」才删除，静默卸载默认保留。取舍是「清理干净」与
  「保留可复用数据」之间的选择，默认偏向后者的安全性。

## 4. 便携版与安装包的差异

| 维度 | 便携 zip | 安装包 setup.exe |
| --- | --- | --- |
| 安装方式 | 解压到任意目录 | 向导安装，可选择目录 |
| 快捷方式 | 无 | 开始菜单必建；桌面可选 |
| 卸载项 | 无 | 有（当前用户） |
| 升级 | 手动覆盖 | 重装覆盖，保留用户数据 |
| 卸载 | 删除目录 | 卸载器清理程序与快捷方式，询问是否删除用户数据 |
| 权限 | 解压即用 | 当前用户安装，不需要 UAC |

两者内容一致（同一套构建产物），差异只在安装/卸载体验与注册表痕迹。

## 5. 禁用词检索证据

当前版本的源码、文档、README、界面文案、资源文件与 CI 配置中不含该词。检索命令与结果：

```powershell
# 1) 工作区与已跟踪文件（-i 忽略大小写；用正则拆分写法，避免检索命令本身包含该词）
git grep -in 'l[i]stary'
# 结果为空（无输出，退出码 1）

# 2) 提交说明
git log --all --oneline --regexp-ignore-case --grep='l[i]stary'
# 结果为空

# 3) 全仓库文件内容与文件名（排除 .git/bin/obj/dist）
Get-ChildItem -Recurse -File |
  Where-Object { $_.FullName -notmatch '\\(\.git|bin|obj|dist)\\' } |
  Select-String -Pattern 'l[i]stary' -CaseSensitive:$false
# 结果为空

# 4) 便携 zip 内容（解压后扫描全部文件）
Expand-Archive -LiteralPath 'dist\Pathleap-1.0.1-win-x64.zip' -DestinationPath $env:TEMP\pathleap-zip-scan -Force
Get-ChildItem $env:TEMP\pathleap-zip-scan -Recurse -File |
  Select-String -Pattern 'l[i]stary' -CaseSensitive:$false
# 结果为空

# 5) 安装包二进制（内容经过压缩，仍做一次兜底检索）
Select-String -LiteralPath 'dist\Pathleap-1.0.1-win-x64-setup.exe' -Pattern 'l[i]stary' -CaseSensitive:$false
# 结果为空
```

说明：历史提交中的 README 内容曾出现该词，按用户要求**不回写历史**；当前 `HEAD` 与重新生成的 zip/安装包
均不含该词。上面的命令可以在任意检出上复现。
