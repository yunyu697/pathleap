# Pathleap 发布检查清单

每次发版（tag `v<版本>`）按顺序核对；任一项不通过则不发版。涉及前台的测量必须单独申请时段，
默认全部走后台/离屏口径。

## 1. 版本与产物

- [ ] `Directory.Build.props` 的 `PathleapVersion` 与 tag 去掉 `v` 后完全一致。
- [ ] 版本格式合法：`<major>.<minor>.<patch>[-alpha<N>]`，`minor` / `patch` ≤ 10。
- [ ] Release 构建成功；`Pathleap.UI.exe` / `Pathleap.Service.exe` 的 `ProductVersion` 等于版本号。
- [ ] `dist\Pathleap-<版本>-win-x64.zip` 存在，且包含 `runtimes\win-x64\native\Microsoft.WindowsAppRuntime.Bootstrap.dll`。
- [ ] `dist\Pathleap-<版本>-win-x64-setup.exe` 存在，文件名带版本号。
- [ ] 安装包静默安装/卸载冒烟通过：安装目录与卸载项可创建，卸载后程序文件与快捷方式清除。
- [ ] CI 两个产物（zip + setup）都上传成功。
- [ ] tag 触发后 GitHub Release 同时包含 zip 与 setup，正文说明两者差异。
- [ ] 公开发布仓库 Release 同时包含 zip、setup 与 `latest.json`；缺 PAT 或签名密钥时 CI 有 warning annotation（不是静默跳过）。
- [ ] `dotnet run --project src/Pathleap.ReleaseTool -- selftest` 全通过。
- [ ] `dotnet run --project src/Pathleap.ReleaseTool -- verify --manifest dist/latest.json` 验签通过；
      清单里的 SHA256 与 `Get-FileHash` 结果一致。
- [ ] 本次发版**未生成新密钥**（未运行 `gen-key`）；`PATHLEAP_SIGNING_KEY` 与客户端内置
      `ReleaseSigning.PublicKeyBase64` 一致（`create` 会硬校验，不一致直接失败、不出清单）。
- [ ] 发布私钥固定不变；如需换钥，已**先**发布内置新公钥的客户端版本，顺序未颠倒。
- [ ] 首个内置签名公钥的版本，发布说明写明「旧版本用户需手动升级」。

## 2. 测试

- [ ] `tools\Test-LpSmoke.ps1 -LpConfiguration Release` 全通过（后台）。
- [ ] `tools\Test-LpUiResults.ps1 -LpConfiguration Release` 全通过（后台，`QUERY`/`NAV`）。
- [ ] 查询性能用 Release 构建复测，P95 ≤ 30 ms；Debug 数据不作为结论。
- [ ] 测试过程未反复抢前台、未向用户活动窗口注入键鼠。
- [ ] 若跑前台唤醒基准：已提前告知时段与预计时长，每轮只集中跑一次，跑完立即让出。
- [ ] **界面改动附真实截图与设计稿并排对照**（`docs/界面对照.html`），逐项列出「设计稿要求 / 当前实现 / 差距 / 是否解决」；截图通道、缩放比例、会话状态已注明。
- [ ] 界面中未接通的控件已在界面上标注「未接入」，并在 README 未完成项中列出，不以假控件糊弄。
- [ ] 无法实测的界面项标注「未验证」或「被环境挡住」，不写成已完成。

## 3. 文档与合规

- [ ] README 已同步（**必过**）：版本号、已实现/未完成能力、性能实测数据及口径、安装/构建方式、已知限制。
- [ ] README 中每个性能数字都能指向 `docs/` 下的实测报告章节。
- [ ] 新增/变更的发布说明已落盘，并写明未完成验证项，不把待验证写成已达成。
- [ ] 禁用词扫描为空：`git grep -in 'l[i]stary'`、`git log --all -i --grep='l[i]stary'`、
      以及排除 `.git/bin/obj/dist` 的全仓库内容扫描。
- [ ] 若历史提交含禁用词：不回写历史，在发布说明中披露并附检索证据。
- [ ] 版本号规则、发布说明与 README 中的产物名一致。

## 4. 收尾

- [ ] 停止所有测试用 `Pathleap.UI.exe` / `Pathleap.Service.exe` 进程。
- [ ] 工作区干净（`git status --short` 无预期外文件）。
- [ ] CI 运行链接与实际结果已回报，失败项如实说明。
