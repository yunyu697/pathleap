# Pathleap 1.1.1 发布说明

发布日期：2026-11-14
版本：`1.1.1`（上一正式版 `1.1.0`）
tag：`v1.1.1`

版本号按 [版本号规则](版本号规则.md) 进位：`1.1.0` 升一个 patch 即 `1.1.1`（`minor`/`patch` 上限为 10，未越界）。

本版把「未接入」清单里剩下的六项全部接回真实功能，设置页的「未接入」标签由 6 处减到 2 处
（只剩「更新通道·预览版」与「更新镜像」）。清单与逐项证据见 [功能状态清单](功能状态清单.md) §1.3、§8.1、§9。

## 1. 浏览器历史与书签（A5）

服务端新增 `BrowserIndex`，读取 Chrome / Edge 每个配置目录下的 `Bookmarks`（JSON）与 `History`（SQLite）：

- SQLite 不直接打开正在使用的库，先把 `History` 复制到临时目录，再经系统 `winsqlite3.dll` 只读查询，退出即删；
- 书签与历史按标题/URL 参与匹配，结果与文件结果合并；`IsBrowser` 让结果行显示「网页」标签与 URL 副标题；
- 单击用系统默认浏览器打开；结果行仍可 `Ctrl+Enter` 在资源管理器中定位（对网页项不可用，走默认浏览器）；
- 默认关闭，范围页开关写 `AppConfig.IncludeBrowserHistory`；服务进程内懒加载一次。

实测（UIA 7/7）：结果出现 10 个「网页」标签、URL 副标题、单击后最近访问新增 1 条 `http` 记录、开关双向写 `config.json`。
截图：[74-browser-results.png](shots/74-browser-results.png)。

## 2. 网络位置（A6）

开启后把两类根作为附加索引：

- `DriveInfo.DriveType.Network` 的已映射驱动器自动包含；
- 用户添加的共享路径（`AppConfig.NetworkLocations`）可增删。

解析由 `ExtrasIndexRoots.Resolve` 完成，`DirectoryIndexSource.BuildMany` 多根遍历写入 `extras.plidx`，
查询时与主索引合并；保存设置后经 IPC `INDEX_EXTRAS` 后台重建。

实测（UIA 7/7 + 端到端 1/1）：附加根内的文件可被搜到；开关与增删都真实写配置并触发重建。
截图：[75-network-locations.png](shots/75-network-locations.png)。

## 3. 索引目录增删（A8）

范围页「索引位置」下可添加/移除本地文件夹（`AppConfig.IndexDirectories`），与网络位置共用附加索引与
`INDEX_EXTRAS` 重建通道；两个来源重叠的根在解析时去掉内层，避免重复条目。

实测（UI 6/6）：界面添加目录后写入配置，并且该目录内文件可被搜到。截图：[76-index-directories.png](shots/76-index-directories.png)。

## 4. 拖放（A11）

主窗 `RootBorder` 接收 `StandardDataFormats.StorageItems`：

- 文件夹用资源管理器打开，文件交给系统默认程序；
- 拖放后窗口收起；
- 失焦隐藏延迟 300ms，并检查左键是否仍按下（拖拽中不抢着隐藏）。

只保留一处 `Drop` 处理器并设 `e.Handled = true`，避免路由冒泡导致同一次拖放处理两遍（曾出现两个资源管理器窗口）。

实测 5/5：真实资源管理器拖拽 → `doDragDrop=Copy` → 日志「拖放打开目录」→ 目录在新标签页打开 → 窗口收起。
截图：[77-drag-drop.png](shots/77-drag-drop.png)。

## 5. 鼠标中键 / 侧键唤醒（A3）

新增 `MouseHook`（`WH_MOUSE_LL`），只在中键/侧键被选为唤醒方式时安装；未选鼠标方式不装钩子。

- 识别 `WM_MBUTTONDOWN` 与 `WM_XBUTTONDOWN`（`XBUTTON1`/`XBUTTON2`）；
- 按下即唤醒浮层，**不拦截按键**，中键新开标签、侧键前进后退照常生效；
- 键盘钩子与鼠标钩子共用 15 秒自检重装（Watchdog）；切换唤醒方式时先卸旧钩子再装新的；
- 快捷键预置由 6 条扩到 9 条（新增鼠标中键、侧键后退、侧键前进），文本可直接解析 `MouseMiddle`/`MouseX1`/`MouseX2`。

实测 7/7：切到侧键与中键各一次，日志「鼠标唤醒已启用」→ Esc 隐藏 → 注入按键 → 「鼠标唤醒触发」+ 窗口显示；
UIA 4/4：设置页三条预置可见、无「未接入」残留。

## 6. 设置页「常规」与「关于」（A12）

设置侧栏由五页扩到七页：

- **常规**：开机启动（真写/删 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 的 `Pathleap` 值，
  命令为 `"<exe>" --tray`；只影响当前账户）、首次使用引导（「重新显示」把 `config.OnboardingDone` 写回 `false`）、
  数据位置（配置/日志目录用资源管理器打开）；
- **关于**：版本与中文名、更新通道（stable/preview）、运行方式（普通权限 / 计划任务提权）、
  `INDEX_STATUS` 实时索引状态、配置路径；「复制诊断信息」把版本/通道/运行方式/索引/配置/日志/系统写入剪贴板，
  不上传；「检查更新」复用更新页入口。

`LpSwitch` 同步补上 UIA `Toggle` 自动化支持（读屏可读写真实状态），本轮验证即用它完成开关操作。

实测 UIA 19/19：两页文案与真实数据路径、开关开启写注册表/关闭删除、重置后 `onboardingDone=false`、
打开配置目录落日志、导航从常规切到关于、关于页版本/通道/运行方式/索引、复制诊断写入剪贴板。

## 7. 未验证项（如实列出）

1. **设置页两页没有新截图**：本轮验证时机器处于锁屏会话，`CopyFromScreen` 只能取到锁屏画面；
   两页证据为 UIA 实测 19/19（包含注册表、`config.json`、日志、剪贴板的真实副作用），截图待下版补齐。
   两张误拍的锁屏图已删除。
2. **提权开关的界面点击链路未跑**：会触发 UAC 与进程重启，本轮未执行；后台计划任务链路此前已实测。
3. **真实 SMB/NAS 共享未验证**：网络位置的端到端用本地临时目录走通（添加 → 附加索引 → 搜到文件）；
   本机没有映射网络驱动器，`DriveType.Network` 自动纳入只做了代码路径审查。
4. **浏览器索引基于本机现有 Chrome/Edge 数据**；未覆盖 Firefox（不支持），也未在全新安装的浏览器配置上验证。
5. **鼠标唤醒用注入按键验证**：没有物理按下中键/侧键；「不拦截」由代码保证（始终 `CallNextHookEx`），未用真实鼠标复测。
6. **提权运行时拖放未实拍**：受 UIPI 限制，普通权限资源管理器不能向管理员窗口拖放，界面与 README 已如实标注。

## 8. 已知限制

- 附加索引（网络位置 / 索引目录）是快照式：新增或移除后需要保存设置触发重建，不做实时监听；
- 浏览器索引在服务进程内懒加载一次，新产生的历史/书签要重启服务才可见；
- 共享离线或不可访问时，该根不产出条目，不影响其它来源；
- 鼠标钩子只在选用鼠标方式时安装，但选中期间会常驻，直到切换为键盘方式；
- 开机启动只写当前用户的 `HKCU`，同一台电脑的其它账户需各自设置；
- 关于页的索引状态依赖后台服务连接，服务未启动时显示「未连接」；
- 拖放在提权运行时受 Windows UIPI 限制（见 §7 第 6 条）。

## 9. 影响范围与升级

- 配置新增字段都有默认值，旧 `config.json` 可直接使用，无需迁移；
- 附加索引快照 `extras.plidx` 在下次保存设置或重建时按新根重写；
- 未选中鼠标唤醒方式时不会安装鼠标钩子，行为与 1.1.0 一致；
- 设置窗新增两页，既有五页的布局与交互未改。

## 10. 发布

产物与 1.1.0 同规则：便携 zip + Windows 安装包，版本号来自 `Directory.Build.props` 的 `PathleapVersion=1.1.1`；
tag 触发 CI 构建、签名与 Release 上传，发布后用 `ReleaseTool verify` 核对验签与资产。
